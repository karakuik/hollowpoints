Welcome to the blog. This is a sample post written in MDX — Markdown with embedded React components.

## What is MDX?

MDX lets you write **Markdown** with embedded JSX. You can import and render React components inline with your prose, which makes it great for technical writing.

## Code example

```js
const greet = (name) => `Hello, ${name}!`
console.log(greet('world'))
```
